# `strata.cluster`

Geometric partitioning K-Means with k-means++ initialization, streaming MiniBatchKMeans, and non-parametric density-based DBSCAN spatial clustering.

---

## Structs & Classes

| Struct | Description |
| :--- | :--- |
| [`KMeans`](KMeans.md) | K-Means clustering using Lloyd's or Elkan's algorithm. |
| [`MiniBatchKMeans`](MiniBatchKMeans.md) | Mini-Batch K-Means clustering algorithm. |
| [`DBSCAN`](DBSCAN.md) | Density-Based Spatial Clustering of Applications with Noise (DBSCAN). |
